# 跨境商品標題產生器

輸入一個商品核心關鍵詞，依「規格詞＋功能詞＋形容詞＋商品核心關鍵詞」結構，一次產生 50 組不重複的英文商品標題，再加上依熱度優先排序、中英對照的另外 50 組，並依 Alibaba 國際站／Amazon 美國站的用字慣例自動切換詞庫。

🔗 **線上使用**：<https://m255525.github.io/product-title-generator/>

⚠️ **需要授權序號才能使用**（見下方「授權序號」一節）。

## 這是什麼

- **核心結構**：規格詞（重量／數量包裝／尺寸）＋功能詞（使用情境）＋形容詞＋商品核心關鍵詞，例如輸入 `green tea powder` 可組出「200g Baking Instantly Green Tea Powder」；核心關鍵詞保證出現在每一組標題（含第二批），不會被同義詞取代。
- **平台切換**：Amazon 美國站／Alibaba 國際站，自動排除或開放批發、MOQ、促銷宣傳詞等平台特定用語。
- **兩批標題**：
  - **第一批 50 組**：隨機不重複組合，離線即可使用，中英對照。
  - **第二批 50 組**：依詞庫熱度分數加權，優先組合較熱門的詞彙（與第一批不重複），中英對照。
  - 兩批表格的「星等」「分級」欄位標題皆可點擊排序；對單一組標題不滿意可按「🔄 換一個」只重新產生那一組。
- **產品說明**（選填）：自由文字描述商品，不影響離線產生的標題，但「AI 熱度評分」與「圖片建議關鍵字」會參考這裡的內容判斷得更準確。
- **AI 熱度評分**（選用，需自備金鑰）：整批標題一次送給你的語言模型，取得貼近平台情境的星等與分級；同時檢查標題是否合理通順、規格／功能／形容詞跟核心關鍵詞搭配是否合理（可參考產品說明）、中英文是否對應，不合格的會自動改寫並標示「✏️ AI 已調整標題」（且保證修正後仍含核心關鍵詞）。
- **圖片建議關鍵字**（選用，需自備金鑰）：上傳商品照片（可搭配產品說明），AI 建議可用的核心關鍵詞候選。
- **CSV 下載**：合併兩批共 100 組標題匯出成檔案，Excel 開啟不亂碼。

## 功能

- **BYOK**：支援 Claude／OpenAI／Gemini／OpenRouter 四選一，API 金鑰只存在瀏覽器 localStorage，不經過任何後端伺服器
- **內建範例**：5 組完全虛構的商品情境（抹茶粉、瑜珈墊、不鏽鋼保溫瓶、寵物潔牙骨、露營LED燈），一鍵套用快速上手
- **授權序號閘門**：整個工具需輸入有效序號才能使用，效期 12 個月
- **可加入主畫面**：支援 PWA 安裝，變成獨立應用程式圖示
- **一鍵清除全部資料**：清空欄位並清除已產生的兩批標題，重新開始
- 響應式版面，桌機／平板／手機皆可使用

## 怎麼用

1. 開啟工具，輸入授權序號
2. （選用）在最上方「API 連線設定」貼上你自己的金鑰（只有 AI 熱度評分／圖片建議關鍵字需要）
3. 選擇目標平台（Amazon／Alibaba），填入核心關鍵詞（英文必填，中文選填），視需要填同義詞與產品說明
4. 按「🎲 產生第一批 50 組」「🔥 產生第二批 50 組」
5. 點擊表格「星等」或「分級」欄位標題可依熱度排序；對單一組不滿意可按「🔄 換一個」；對任一批按「🚀 AI 熱度評分」，或上傳圖片取得關鍵字建議
6. 按「⬇ 下載 CSV（100 組）」匯出

詳細操作說明見 [manual.html](manual.html)。

## 技術架構

純前端單檔工具，**沒有任何建置流程、框架、npm 依賴**：

| 項目 | 做法 |
|---|---|
| 標題產生 | 純前端字串組裝＋加權隨機抽樣，不連網 |
| 離線熱度分數 | 內建人工預先標註的參考分數（非真實搜尋數據） |
| AI 熱度評分／圖片分析 | 瀏覽器直接 `fetch` 你選擇的 LLM 服務商官方 API（無後端代理） |
| 金鑰儲存 | `localStorage`，只在使用者自己的瀏覽器裡 |
| 授權序號驗證 | Google Sheet + Google Apps Script（免費輕量後端），只做序號驗證，不經手商品資訊或標題內容 |
| 頂部跑馬燈 | 與工作區其他工具共用同一個公告來源（可選、失敗不影響主功能） |

## 本機開發

不需要任何建置工具或安裝依賴，純靜態檔案：

```bash
git clone https://github.com/M255525/product-title-generator.git
cd product-title-generator
python -m http.server 8000
```

開啟 `http://localhost:8000`（本機測試序號閘門需先部署自己的 Apps Script 後端，見 `SETUP-授權伺服器設定.md`）。


## 隱私與資料

本 repo 公開的只有程式碼。你填寫的商品資訊、產生的標題只存在自己瀏覽器的 localStorage；按下「AI 熱度評分」或「分析圖片」時，這些內容會直接連線送到你選擇的 AI 服務商，不經過本工具作者或任何第三方伺服器。授權序號驗證只會傳送序號本身給驗證伺服器，不會傳送任何商品資訊或標題內容。
