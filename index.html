PRODUCT TITLE GENERATOR

一個核心關鍵詞，組出上百組跨境電商標題

依「規格詞＋功能詞＋形容詞＋商品核心關鍵詞」結構，一次產生 50 組不重複標題＋另 50 組中英對照熱門優先標題，並依 Alibaba／Amazon 平台規則自動套用不同用字。

AIAPI 連線設定（AI 熱度評分／圖片分析共用）
API 連線設定

金鑰只存在這台電腦的瀏覽器（localStorage），不會送到本工具以外的任何地方；圖片分析需使用支援視覺輸入的模型（例如 Claude、GPT-4o、Gemini 系列）。未設定金鑰不影響第一批／第二批標題產生與 CSV 下載等離線功能。

✎商品資訊設定
①第一批 50 組（隨機不重複）

依目前平台，隨機組合「規格詞＋功能詞＋形容詞＋核心關鍵詞（含同義詞）」，去重後湊滿 50 組，同時附中文對照標題。星等為離線參考分數，可另外呼叫 AI 即時評分覆蓋；點擊「星等」或「分級」欄位標題可依熱度排序。

②第二批 50 組（熱度優先＋中英對照）

依詞庫熱度分數加權抽樣，優先組合分數較高的詞彙（與第一批不重複），同時輸出中文標題供語意核對；點擊「星等」或「分級」欄位標題可依熱度排序。

🖼上傳圖片取得標題建議字（選用，需 BYOK）

上傳商品照片，串接下方的語言模型分析圖片內容，建議可用於核心關鍵詞的候選詞（中英對照），以及僅供參考的賣點／情境形容詞建議。

⬇下載 CSV

合併輸出第一批＋第二批共 100 組標題（含星等、分級、規格／功能／形容詞拆解），Excel 開啟不會有中文亂碼。

使用警語
  • 本工具產生的「熱門搜尋程度」星等與分級，未串接 AI 前為內建離線參考分數，串接 AI 後為模型的主觀評估——兩者皆非 Alibaba／Amazon 平台真實即時搜尋數據，不保證實際上架成效，正式上架前請自行以平台後台工具或人工判斷覆核。
  • 本工具依公開資訊整理 Amazon／Alibaba 的一般標題慣例（如 Amazon 避免主觀宣傳詞、Alibaba 允許批發／MOQ 用語）供參考，實際規則以各平台當下公告的政策為準，正式刊登前請自行確認。
  • 請勿在任何欄位或上傳圖片中包含真實個資、公司機密或受著作權保護的他人內容——欄位資料只存在你自己瀏覽器的 localStorage，不會上傳到任何伺服器，但送出給 AI 服務後的隱私仍由該服務條款規範。
  • 「AI 熱度評分」與「圖片分析」需要你自行填入 API 金鑰，該金鑰只存在你的瀏覽器，按下功能時會直接連線到你選擇的服務商，本工具不會經手或保存金鑰，也不會向你收取任何 API 費用——實際費用依你與該服務商的方案計算。
  • AI 產出的評分、關鍵字建議可能有誤，正式使用前請自行檢查；本工具與創作者不對後續實際上架成效負責。
