操作手冊

依「規格詞＋功能詞＋形容詞＋商品核心關鍵詞」結構，只需一個核心關鍵詞就能一次產生 50 組不重複標題，再加上依熱度優先排序、中英對照的另外 50 組，並依 Alibaba 國際站／Amazon 美國站的用字慣例自動切換詞庫。

功能總覽

  • 平台切換：Amazon 美國站／Alibaba 國際站，自動套用不同的詞庫與大小寫規則
  • 核心關鍵詞保證出現：不論第一批或第二批，每一組標題都一定包含你填的核心關鍵詞（英文），不會被同義詞取代掉
  • 第一批 50 組：隨機不重複組合，離線即可使用，中英對照
  • 第二批 50 組：依詞庫熱度分數加權，優先組合較熱門的詞彙，中英對照
  • 排序：兩批標題表格的「星等」「分級」欄位標題皆可點擊排序（依熱度高低切換）
  • 單筆換一個：對某一組標題不滿意，可按該列的「🔄 換一個」只重新產生這一組，其餘標題不受影響
  • AI 熱度評分（選用，需自備金鑰）：把整批標題送給你的語言模型，取得更貼近平台情境的星等與分級，同時檢查標題合理性並可自動修正
  • 圖片建議關鍵字（選用，需自備金鑰）：上傳商品照片，AI 建議可用的核心關鍵詞候選
  • CSV 下載：合併兩批共 100 組標題，含星等／分級／規格拆解，Excel 開啟不亂碼
  • 加入主畫面：可安裝成獨立應用程式圖示，不用每次開瀏覽器輸入網址

操作步驟

  1. （選用）在最上方「API 連線設定」填入你自己的金鑰——只有「AI 熱度評分」「圖片建議關鍵字」需要，其餘功能離線即可使用
  2. 先套用一個「範例」快速看懂欄位怎麼填，或直接從空白開始
  3. 在最上方選擇目標平台（Amazon 美國站／Alibaba 國際站）——這會決定可用的形容詞／功能詞範圍與大小寫規則
  4. 填入「核心關鍵詞（英文）」（必填），選填中文核心關鍵詞（供中文標題使用）與同義詞／相關詞（選填，每行一個，只用於第一批增加變化）
  5. 按「🎲 產生第一批 50 組」，下方會出現隨機不重複的中英對照標題表格，附離線參考星等與分級
  6. 按「🔥 產生第二批 50 組」，會依詞庫熱度分數加權，優先組合較熱門的詞彙（與第一批不重複），同樣中英對照
  7. 點擊表格的「星等」或「分級」欄位標題，可依熱度高低排序該批標題，再點一次切換排序方向
  8. 對某一組標題不滿意，按該列最右邊的「🔄 換一個」，只會重新產生這一組（仍保證含核心關鍵詞、不與同批其他標題重複），其餘 49 組不動
  9. （選用）已填好金鑰的話，可對任一批按「🚀 AI 熱度評分」，用語言模型重新評估星等與分級，同時檢查標題合理性並可自動修正
  10. （選用）上傳商品圖片，按「🔍 分析圖片建議關鍵字」，取得核心關鍵詞候選，點擊即可套用
  11. 按「⬇ 下載 CSV（100 組）」把兩批標題匯出成檔案
切換平台會清空目前已產生的兩批標題（不同平台的詞庫不同，避免混用），套用前會先詢問確認。
排序只影響畫面顯示順序，重新按「產生」會恢復原始順序；CSV 下載內容不受排序影響。

平台規則差異（Amazon 美國站 vs Alibaba 國際站）

Amazon 美國站：自動排除官方一般不建議出現在標題的主觀宣傳詞（如 Best、#1、Sale、Free Shipping、促銷字樣）與批發／MOQ 用語；標題套用 Title Case（每個實詞字首大寫）。

Alibaba 國際站：開放批發（Wholesale）、大量（Bulk）、代工客製（OEM）、工廠直營（Factory Direct）等 B2B 詢價情境常見用語。

本工具依公開資訊整理一般性慣例供參考，並非兩平台的官方規則全文，正式刊登前請自行以平台當下公告的政策為準。

「熱門搜尋程度」星等與分級是怎麼算的

離線參考分數：詞庫裡每個規格詞／功能詞／形容詞都預先標註了 1～5 的粗略參考熱度分（依電商常識與常見高轉換字詞人工評定），一組標題的星等＝三個詞的平均分數四捨五入，對應 S／A／B／C／D 分級。

AI 即時評分：按「🚀 AI 熱度評分」後，會把該批標題整批送給你設定的語言模型，請它依平台情境重新評估星等與分級，並附簡短理由（滑鼠移到分級標籤上可看到）——這是模型的主觀判斷，同樣不是真實搜尋數據。

同時檢查標題合理性：AI 評分時也會一併檢查每組標題（1）英文本身是否通順合理（例如文法錯誤、單字重複、語意矛盾或搭配奇怪）、（2）規格詞／功能詞／形容詞跟核心關鍵詞放在一起是否合理搭配（例如把「護膚用」放在瑜珈墊這種跟護膚無關的商品上）、（3）中文標題是否確實對應英文標題的意思——三項只要有一項不合格，就會給出修正後的英文／中文標題並自動套用，且修正後一定仍保留核心關鍵詞本身。這種標題在表格裡的英文標題下方會顯示「✏️ AI 已調整標題」，滑鼠移到上面可看調整理由；「拆解」欄位也會改顯示「（英文標題經 AI 調整，無對應拆解）」，因為調整後的用字不一定還能對應原本的規格／功能／形容詞拆解。

AI 調整標題後，原始（未調整）版本不會另外保留；若不滿意調整結果，可對該列按「🔄 換一個」重新隨機產生，或重新按一次「產生」該批標題整批重來，也可以手動修改核心關鍵詞後重新產生。
請注意：兩種評分方式都不是 Alibaba／Amazon 平台的真實即時搜尋數據（這類數據不對一般使用者開放 API），僅供發想與初步篩選參考，正式上架前請自行以平台後台工具或人工判斷覆核。

🔍 上傳圖片取得標題建議字（選用，需先填好 API 金鑰）

  1. 先在「API 連線設定」填好服務商／模型／金鑰——需使用支援視覺輸入的模型（例如 Claude、GPT-4o、Gemini 系列）
  2. 在「上傳圖片取得標題建議字」區塊選擇一張商品照片
  3. 按「🔍 分析圖片建議關鍵字」，AI 會判斷圖片內容並建議 2～3 個核心關鍵詞候選（中英對照）
  4. 點擊候選詞即可直接套用到「核心關鍵詞」欄位（若欄位已有內容會先詢問是否覆蓋）
同時顯示的「賣點／情境建議」僅供你自行參考發想，不會自動套用——因為這些詞不一定落在系統內建的規格／功能／形容詞詞庫裡。

送給 AI 評分／分析（選用，需自備 API 金鑰）

「AI 熱度評分」與「圖片分析」共用同一組 API 連線設定。

  1. 展開「API 連線設定」，選擇服務商（Claude／OpenAI／Gemini／OpenRouter），填入你自己申請的 API 金鑰；模型欄有預設值，也可以自行改成你想用的模型 ID
  2. AI 熱度評分一次處理一整批（最多 50 筆），用單一次 API 呼叫取代逐筆呼叫，避免過多次請求的成本與延遲
API 金鑰要自己到各服務商網站申請，使用時依你與該服務商的方案計費，本工具不會向你收費，也不會經手你的金鑰——金鑰只存在你這台電腦的瀏覽器，且直接連到服務商官方 API。未設定金鑰完全不影響第一批／第二批標題產生、離線星等與 CSV 下載。

CSV 下載

按「⬇ 下載 CSV（100 組）」會合併輸出第一批＋第二批的所有標題（若某一批尚未產生則只輸出已產生的部分），欄位包含：批次／標題(英)／標題(中)／星等／分級／規格詞／功能詞／形容詞／核心關鍵詞／適用平台。檔案已內建 UTF-8 BOM，Excel 開啟中文欄位不會亂碼。

本工具需先輸入授權序號並按「確認」驗證通過，才能使用整個工具（不是只鎖某個功能）。序號自第一次驗證起提供 12 個月使用期限，驗證結果每次開啟頁面都會即時向授權伺服器重新確認，並每 20 分鐘在背景重新驗證一次——序號到期時，畫面會在最多 20 分鐘內自動重新鎖定。
